#                 EVotingSystem                          #
#            A Simple Java Voting App                    #
###########################################################

📌 FEATURES
-----------------------------------------------------------
• Voter Registration and Login
• Candidate Management by Admin
• One-Person-One-Vote Enforcement
• Auto Vote Tallying and Result Display

🛠️ REQUIREMENTS
-----------------------------------------------------------
• Java JDK 8 or higher
• Git (for cloning the repository)

📥 INSTALLATION & USAGE
-----------------------------------------------------------
$ git clone https://github.com/Pathhari/EVotingSystem.git
$ cd EVotingSystem
$ javac *.java
$ java Main

📁 PROJECT STRUCTURE
-----------------------------------------------------------
EVotingSystem/
├── Admin.java
├── Candidate.java
├── Main.java
├── Voter.java
├── VoterList.java
└── (additional helper files)

🚀 HOW IT WORKS
-----------------------------------------------------------
[1] Admin logs in and adds candidates.
[2] Voter registers and logs in.
[3] Voter casts a vote (only once).
[4] System tallies and shows results.
